**Snake Game** is a classic arcade game where the player controls a growing snake to collect food and increase their score. The snake must avoid colliding with the walls and its own body. The game ends upon collision.

### 🔹 Key Features:

* Arrow key controls for movement
* Snake grows after eating food
* Game ends on collision
* **Library used:** `Pygame`
